Semantic representation
Semantic search aims to match meaning and intent.
An embedding maps text into a numeric vector.
Related passages can have nearby vectors.
A query encoder creates a vector for the question.
A document encoder represents candidate content.
Vector dimensions store learned features of meaning.
Training data teaches the encoder useful relationships.
Similar terms can be close despite different spelling.
Context can change the meaning of a word.
Nearest neighbor retrieval
A similarity measure compares query and document vectors.
Cosine similarity compares their orientation.
The system can retrieve the closest document vectors.
A vector index accelerates neighbor lookup.
Approximate search trades some precision for speed.
The number of neighbors controls result breadth.
A threshold can exclude weak matches.
Retrieved passages should preserve their source identifiers.
A snippet gives context for the semantic match.
Hybrid retrieval
Keyword search matches exact indexed terms.
Semantic search can match paraphrases.
A hybrid system combines both result lists.
Exact matches are useful for names and codes.
Vector matches help with broad natural language questions.
A ranking step can combine different scores.
Score scales may need normalization.
Duplicate passages can be collapsed before presentation.
Query intent can guide the retrieval method.
Evaluation
Test queries should include paraphrased requests.
Relevant passages need a human judgment label.
Recall can measure whether related text was found.
Ranking metrics reward placing useful passages higher.
Latency tests reveal expensive vector searches.
A baseline keyword search provides comparison.
Evaluation should include uncommon vocabulary.
Error analysis can find ambiguous queries.
Metrics should be checked by topic.
Deployment and limits
Large vector collections can use substantial memory.
Batch encoding can speed document preparation.
Hardware affects embedding latency.
Model versions should be stored with the index.
A new model may require a full rebuild.
Private documents need suitable access controls.
Embeddings can retain information from their text.
Results should link back to original content.
Semantic scores do not prove factual correctness.
