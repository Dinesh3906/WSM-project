Distributed search divides a large document collection across several machines. Each shard stores part of an index, and a coordinator sends a query to the relevant shards. The nodes retrieve local matches and return document identifiers and scores. Replication keeps copies of data available when a machine fails. Load balancing spreads requests so one server does not become a bottleneck. Distributed indexing allows a search service to grow as more documents and users are added, but it also requires careful coordination and monitoring.
