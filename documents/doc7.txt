Search ranking orders documents by relevance to a user query. A retrieval model compares query terms with document terms. Term frequency indicates how often a term occurs, while inverse document frequency favors words that distinguish one document from the corpus. TF-IDF weights combine these signals. PageRank uses links in a graph of web pages to estimate authority. Modern search engines combine text relevance, link quality, freshness, and user context. Clear ranking metrics help developers evaluate whether the best results appear first.
