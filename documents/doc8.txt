Boolean retrieval models combine search terms with AND, OR, and NOT. AND returns documents that contain both terms, OR returns documents containing either term, and NOT excludes a term from the result set. Each operation can use document ID sets from postings lists in an inverted index. Parentheses group a complex query and make its meaning explicit. Query processing applies set intersection, union, and difference. Students can test each operator against a small corpus and compare matching document names. Wildcard expansion can turn one term pattern into several vocabulary terms.
