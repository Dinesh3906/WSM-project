Databases organize records for fast lookup, filtering, sorting, and joins. A B-tree index stores keys in sorted pages so queries can find matching rows without scanning every record. Hash tables support exact key lookup, while an inverted index is useful for full-text search. Database query planners compare indexes and choose an efficient execution plan. Terms, values, and document identifiers are common building blocks across data systems. Indexes speed retrieval but take memory and must be updated when data changes. Understanding this tradeoff helps programmers build reliable search applications.
